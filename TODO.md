# Safar — Feature Backlog & Roadmap 🚀

## Completed Features (MVP)
- [x] LangGraph 5-agent state machine implementation.
- [x] Structured LLM generation with Google Gemini (`gemini-2.5-flash`).
- [x] External Open-Meteo Weather & Geocoding API tool integration.
- [x] FastAPI REST API with input validation and error fallbacks.
- [x] Modern React + Vite frontend with glassmorphism UI & agent progress animation.
- [x] Replanning mechanism with target feedback execution.
- [x] Automated Pytest suite covering models, weather tools, state, and endpoints.
- [x] Full documentation suite.

## Planned Enhancements (Post-MVP)
- [ ] **Interactive Map View**: Leaflet / Mapbox integration for daily itinerary pins.
- [ ] **Export to Calendar**: Download `.ics` files for scheduled day activities.
- [ ] **User Authentication & Saved Trips**: User accounts with saved past itineraries.
- [ ] **Flight & Hotel Live Search**: Integration with SerpAPI / Skyscanner / Booking.com tools.
- [ ] **Multi-Currency Converter**: Live exchange rates using Open Exchange Rates API.
